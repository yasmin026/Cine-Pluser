# 🎬 CinePulse

> Uma plataforma web moderna de catálogo de filmes e séries desenvolvida com foco em UI/UX, permitindo busca em tempo real, filtros por categoria e gestão de lista pessoal de favoritos.

---

## 🚀 Funcionalidades

* **Catálogo Dinâmico:** Visualização de filmes em destaque com cartões interativos em tema escuro.
* **Busca em Tempo Real:** Pesquisa instantânea por títulos e sinopses.
* **Filtros por Categoria:** Navegação rápida entre gêneros (Ação, Ficção Científica, Animação, Drama, etc.).
* **Lista de Favoritos (Watchlist):** Adiciona e remove filmes da tua lista pessoal com persistência de dados via `localStorage`.
* **Detalhes do Filme:** Modal interativo com sinopse completa, ano de lançamento, avaliações e elenco principal.
* **Suporte a API Externa:** Estrutura pronta para integração com a API oficial do TMDB.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias modernas de front-end sem a necessidade de frameworks complexos:

* **HTML5 Semantic**
* **Tailwind CSS** (para estilização rápida e design responsivo com *Glassmorphism*)
* **JavaScript (ES6+)** (para manipulação de DOM, estado e eventos)
* **FontAwesome** (para ícones modernos)
* **LocalStorage API** (para persistência da lista de favoritos)
